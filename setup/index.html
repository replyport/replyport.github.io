ReplyPort · Setup guide

Set up ReplyPort for your AI.

Before you start

  • Use ReplyPort only from its official ChatGPT/Codex or Claude directory listing when that listing becomes available.
  • Have a Dropbox account, Dropbox Desktop, Outlook Classic and a supported Windows PC.
  • Keep Dropbox Desktop signed in to the same Dropbox account you authorize in the connector.

On this page

Setup steps If setup stops

Connect ReplyPort

  1. Open the official directory listing

    Find ReplyPort in the ChatGPT/Codex Plugins Directory or Claude Connectors Directory and choose Connect. Public listings are still pending provider submission and approval. Do not use an unpublished connector URL.

  2. Authorize your Dropbox account

    Sign in to the Dropbox account that will hold ReplyPort’s App Folder. Review the requested Dropbox permissions. This Dropbox authorization identifies your ReplyPort connection; no separate ReplyPort website account is needed.

  3. Install the Windows app

    If needed, install ReplyPort from the Microsoft Store. Sign in to Dropbox Desktop on the same PC with the same Dropbox account.

  4. Choose your Outlook mail

    Open Outlook Classic and ReplyPort Control Centre. Connect the mailbox you want to use, choose the ordinary folders and history period, and enable copying. New Outlook is not supported.

  5. Keep the local app available

    Leave the PC on, ReplyPort running, and Dropbox syncing while you search or request drafts. Outlook Classic must be open when a draft is created. If the app is unavailable, requests can stay pending.

  6. Search a message you know is mirrored

    Ask ChatGPT, Codex or Claude to search for a specific message after Dropbox has synced. The Windows ReplyPort app processes the search request.

  7. Request a draft and check its status

    Give the AI clear message, recipient, subject and text details. A request being queued does not mean an Outlook draft exists. Only a matching receipt with status created confirms that ReplyPort created an unsent draft.

  8. Review and disconnect when needed

    Review the native draft in Outlook Classic and decide yourself whether to send it. To disconnect, remove ReplyPort from the host. To revoke Dropbox access too, remove ReplyPort separately from Dropbox Connected Apps.

ReplyPort has no Send tool. Review every draft in Outlook and decide whether to send it yourself. See how the hosted connector works and the Privacy policy.

If setup stops

ReplyPort is not in the directory
The production service has passed product acceptance, but public directory listings are still pending. Do not connect through an unpublished URL. Use the current Windows-app instructions in product documentation or wait for the official listing.
Dropbox sign-in selected the wrong account
Disconnect ReplyPort in the host, revoke ReplyPort from that Dropbox account's Connected Apps if needed, then start again and select the account used by Dropbox Desktop and ReplyPort on the PC.
Search returns no results or stays pending
Check that mail copying is enabled for the correct Outlook mailbox and period, Dropbox has synced, and ReplyPort is running on the PC. Search only covers copies available in the ReplyPort App Folder.
The draft has not appeared in Outlook
Keep the PC on, ReplyPort running, Outlook Classic open and Dropbox syncing. Check draft status. A pending or deferred request is not a created draft; a matching created receipt confirms creation.
You need more help
See the ReplyPort support page and include the visible error or status code. Do not send message bodies, OAuth tokens, passwords or other credentials.
