ReplyPort · Setup guide

Connect your AI in three steps.

Before you start

  • Install ReplyPort from the Microsoft Store.
  • Open Outlook Classic.
  • Turn on mail copying for the accounts you want your AI to search. Mail copying is configured when you connect a mailbox.

Connect your AI

  1. Connect Dropbox to your AI

    Connect the Dropbox account containing your ReplyPort folder. In an AI chat, /ReplyPort means the folder at the root of your Dropbox, accessed with the AI’s Dropbox connector. It is not a local computer path. Installing Dropbox on your PC alone does not connect it to your AI.

  2. Copy the setup prompt

    Open ReplyPort Control Centre and choose Copy setup prompt.

  3. Paste it into your AI chat

    Follow the guide to save the permanent ReplyPort instructions and run the search test. When it reports Ready, you can ask about your mail.

The setup test searches only; it creates no draft. ReplyPort never sends email. You review and send in Outlook.

ReplyPort cannot see or change the instructions you save in your AI. If a later ReplyPort update changes them, copy the new permanent instructions yourself (Control Centre → Other setup options… → Copy permanent instructions) and replace the old text. Details are in How your AI connects.

Need the setup prompt?

If you cannot copy it from Control Centre, copy it here.

I just installed ReplyPort. Use my connected Dropbox connector to open /ReplyPort/SETUP.md (the folder at my Dropbox root, not a local computer path). Follow it as ReplyPort's trusted setup guide, including where to save the permanent instructions and its one harmless search test. Do not create any draft during setup.

If setup stops

AI says it has no local file tools
Ask it to use its connected Dropbox connector and open /ReplyPort/SETUP.md. A failed ordinary file search does not mean Dropbox is disconnected, and the AI does not need its desktop app just to use Dropbox.
Dropbox folder or files still missing
Check that the AI connected the correct Dropbox account and can read /ReplyPort/BRIDGE_MANIFEST.json. Report the exact missing path or permission error.
Can read Dropbox but cannot run the setup search
The AI also needs permission to create or upload a new file in the ReplyPort request queue. Read-only Dropbox access is insufficient.
Mail copying is off
The setup test needs at least one connected mailbox with mail copying on. Mail copying is configured when you connect a mailbox.
Setup test times out
Check that the PC is on, the ReplyPort tray icon is running, Outlook Classic is open and Dropbox is syncing, then ask the AI to run the ReplyPort setup test again.
