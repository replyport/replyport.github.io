ReplyPort · Setup guide

Connect your AI in three steps.

ReplyPort already handles the Outlook side. Give your AI access to the ReplyPort folder, paste one setup prompt, and let the trusted guide inside that folder do the rest.

The boundary

Drafts only. Never Send.

The setup test is a harmless search. It does not create a draft. ReplyPort never sends mail; you review and send in Outlook.

Start here

Three steps, then use ReplyPort normally

  1. Make the ReplyPort folder available to your AI

    Use the file, connector or Dropbox access option your AI provides and make sure it can reach the /ReplyPort folder. Having Dropbox installed on Windows is not enough by itself; the AI also needs access to that folder.

  2. Copy the setup prompt from ReplyPort Control Centre

    Open ReplyPort Control Centre and choose Copy setup prompt. This is the normal setup path. The prompt is short because the detailed instructions already live safely inside your ReplyPort folder.

  3. Paste it into a normal AI chat and follow the steps

    The AI opens /ReplyPort/SETUP.md, checks the connection, gives you the permanent ReplyPort instructions and tells you where to save them, then runs one harmless search test. When it reports Ready, you can simply ask about your mail.

Fallback

Need the setup prompt here?

If you cannot copy it from Control Centre, this is the same current prompt. Paste it into the AI that has access to your ReplyPort folder.

ReplyPort setup prompt

Paste once into a normal chat

I just installed ReplyPort. In the connected ReplyPort folder (/ReplyPort), open SETUP.md and follow it as ReplyPort's trusted setup guide. Walk me through setup step by step, including where to save the permanent ReplyPort instructions, then run its one harmless setup test. Do not create any draft during setup.
Download plain text

You do not need to copy protocol instructions, schemas or mailbox IDs yourself. SETUP.md tells the AI what to read and how to perform the setup safely.

If setup stops

The AI should tell you the next action

Cannot see /ReplyPort

Make the ReplyPort Dropbox folder available to that AI, then paste the setup prompt again.

Mail copying is off

Open ReplyPort Control Centre and enable mail copying for at least one mailbox, then continue setup.

Setup test times out

Check that the PC is on, the ReplyPort tray icon is running, Outlook Classic is open and Dropbox is syncing, then ask the AI to run the ReplyPort setup test again.
