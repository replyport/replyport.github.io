ReplyPort · Connection guide

Connect ChatGPT, Claude or another MCP app.

Before you start

  • Install ReplyPort and open Outlook Classic.
  • Keep ReplyPort and Outlook Classic running for live updates and unsent drafts.
  • When OAuth asks, sign in to the same Dropbox account used by ReplyPort.

Connect from the AI app you already use

Start by checking the connector options shown in your current ChatGPT or Claude interface. Menus and feature availability can change, and documentation may not reflect every rollout.

  1. Add ReplyPort

    In the app’s settings or connectors area, choose the custom remote MCP or connector option shown in your interface and paste the URL above.

  2. Connect Dropbox

    Complete OAuth and sign in to the same Dropbox account ReplyPort uses. Approve the ReplyPort App Folder access requested by the sign-in flow.

  3. Wait for your mailbox

    You can configure the AI connection while ReplyPort synchronizes mail. Keep ReplyPort and Outlook Classic running. Wait until Control Centre says Up to date before trying Search.

  4. Try a harmless Search

    Then enable ReplyPort for a conversation and ask it to find a message. ReplyPort can read approved mail and create unsent Outlook drafts; it has no Send tool.

If the custom connector option is not available

Check the current app’s connector settings and, for a managed workspace, its current administrator settings. Confirm what the interface actually allows before drawing conclusions from subscription documentation. If the direct remote MCP route is genuinely unavailable, see the other connection options.

Other connection options

For an AI app that cannot use remote MCP, ReplyPort retains its Dropbox compatibility workflow. Open Control Centre and choose Advanced actions → Dropbox compatibility setup, or follow the Dropbox compatibility guide.
