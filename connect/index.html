Connect ChatGPT, Claude or another MCP app.

Before you start

  • Install ReplyPort and open Outlook Classic.
  • Keep ReplyPort and Outlook Classic running for live updates and unsent drafts.
  • When OAuth asks, sign in to the same Dropbox account used by ReplyPort.

ChatGPT and Claude

ReplyPort’s public directory listings are pending. You can connect manually if your account and AI app allow custom remote MCP connections.

ChatGPT

For full MCP access, including ReplyPort’s draft tools, use ChatGPT Business or Enterprise/Edu on the web. ChatGPT Pro can connect to custom MCP servers with read/fetch permissions only, so its users cannot use ReplyPort draft actions. Go to Plugins → + → Add custom MCP server, enter the URL below and configure OAuth. Business admins or owners create and publish connections. Enterprise/Edu admins can authorize members to create them; admins or owners publish. Workspace rules apply. See OpenAI’s custom MCP setup instructions.

Claude

Anthropic currently supports custom remote MCP connectors on Claude Free, Pro, Max, Ultra, Team and Enterprise. Free accounts are limited to one custom connector. Team and Enterprise owners must enable connectors for their organization. In Claude, go to Customize → Connectors → Add → Custom → Web, add the URL below and choose an OAuth sign-in option. Follow Anthropic’s connector instructions.

Other MCP-compatible apps

Use an app that supports remote MCP over HTTPS and OAuth. Add this server URL:

  1. Add the remote server

    Choose your app’s custom MCP, remote server or web connector option and paste the URL above.

  2. Sign in with OAuth

    Choose the sign-in option. When ReplyPort opens Dropbox, use the same Dropbox account that ReplyPort uses.

  3. Start with Search

    Enable ReplyPort for a conversation and ask for a harmless mail search. ReplyPort provides mail search, reading and draft tools. It has no Send tool.

Some apps require a particular plan, workspace permission or administrator approval. If the app cannot connect to a remote OAuth-protected MCP server, use the Dropbox compatibility setup.

Dropbox compatibility setup

For an AI app that cannot use remote MCP, use the older Dropbox connector workflow. Open ReplyPort Control Centre and choose Advanced actions → Dropbox compatibility setup, or follow the Dropbox compatibility guide.
