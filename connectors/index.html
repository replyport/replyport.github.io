ReplyPort · Connector setup

Connect ReplyPort to ChatGPT or Claude.

The optional hosted connector lets an eligible AI host work with approved ReplyPort mail copies and draft requests. Outlook stays on your Windows PC.

Not ready for customer mail

The hosted service is deployed but has not passed its customer rollout gates. ChatGPT and Claude public listings are not verified live. Do not connect a real mailbox or use an unpublished connector link.

Before you connect

  • Install ReplyPort from the Microsoft Store on a supported Windows PC.
  • Use Outlook Classic with the accounts you want ReplyPort to process, and keep Outlook open when local draft creation is needed. New Outlook is not supported.
  • Install Dropbox Desktop and sign in on that PC. In ReplyPort Control Centre, connect the Dropbox account and choose which mailboxes, folders and optional attachments to mirror.
  • Use a ChatGPT account and workspace that permit the connector and MCP write actions. Availability depends on plan, region, workspace settings and administrator controls. Full MCP write actions are currently available in eligible Business, Enterprise and Edu workspaces.
  • Use Claude on a plan that supports remote MCP connectors (currently Pro, Max, Team or Enterprise). A Team or Enterprise owner may need to enable the connector for the organization.
  • Use ReplyPort only where you have authority to process the mail and your organization permits Dropbox and the selected AI host.

The older Dropbox connector setup guide describes the current Windows-app workflow. For the hosted MCP connector, you will authorize the same Dropbox account inside the ReplyPort connector sign-in flow; you do not need to add a separate Dropbox connector to the AI host.

Connect the hosted ReplyPort connector

  1. Install ReplyPort and choose mail

    Connect Dropbox and Outlook Classic in ReplyPort. Turn on copying only for the mailboxes and folders you approve. The app copies eligible mail to ReplyPort’s dedicated Dropbox App Folder.

  2. Open the official directory listing

    After provider approval, find ReplyPort in ChatGPT’s plugin directory or Claude’s connectors directory and follow that host’s connection steps. No public install link is available yet.

  3. Authorize the same Dropbox account

    During ReplyPort’s sign-in flow, choose the Dropbox account that contains the App Folder used by ReplyPort on your PC. Review the requested App Folder permissions before approving. Each AI host connection has its own authorization.

  4. Run a search, then check draft status

    Ask the AI to search for a specific message you know is mirrored. For a draft, wait for ReplyPort’s matching receipt. A queued request is not a created Outlook draft; the status must say created.

What the hosted service processes

The ReplyPort-operated Cloudflare MCP service uses the Dropbox authorization you approve to read approved mirrored message metadata, snippets and bodies from ReplyPort’s Dropbox App Folder. It returns requested search or message content to the connected ChatGPT or Claude host. For a draft request, it writes a request record to Dropbox and can return the local worker’s receipt status.

The hosted service does not connect to Outlook or keep a second mailbox mirror. The ReplyPort Windows app on your PC is the Outlook executor. Cloudflare hosts the service; Dropbox stores and transfers the authorized records; and the AI host processes the content returned to its conversation. See the Privacy policy for the service, providers, retention and logging details.

ReplyPort creates drafts; you send manually

ReplyPort has no Send tool or cloud mail-send path. The local Windows app checks a request and creates a native unsent Outlook draft in the correct account. Review the draft in Outlook Classic, edit or discard it, and press Send yourself if you choose.

If the PC, ReplyPort or Outlook is offline, some operations may remain pending. Do not treat a request submission or a pending or deferred status as a created draft. Only a matching receipt with status: created confirms creation.

Disconnect and remove data

  • Remove or disconnect ReplyPort in the ChatGPT or Claude connector settings to revoke that host’s ReplyPort authorization. Each host has a separate authorization.
  • Disconnecting the AI host may not revoke its linked Dropbox authorization. To revoke Dropbox access, remove ReplyPort from the connected apps in your Dropbox account settings.
  • Disconnecting does not delete mirrored files, draft requests or receipts in Dropbox, and does not remove Outlook drafts. Use ReplyPort Control Centre’s removal option or manage Dropbox files directly if you want to remove mirrored data.

Revocation and file deletion are separate. The Privacy policy describes provider-side records and the limits of deletion timing.

Troubleshooting

ReplyPort is not available in the host
Directory approval and account availability are still pending. Do not use a copied or unofficial connector URL. Check the official listing after ReplyPort announces availability.
Dropbox sign-in selected the wrong account
Disconnect the ReplyPort host connection, revoke ReplyPort under that Dropbox account’s connected apps if needed, then start again and choose the account containing the ReplyPort App Folder.
The search returns no results or remains pending
Check that mail copying is enabled for the correct Outlook mailbox and period, Dropbox has synced, and the selected AI host is connected to the same Dropbox account. Pending searches need the Windows ReplyPort worker to process them.
The draft has not appeared in Outlook
Keep the PC on, ReplyPort running and Outlook Classic open. Check the request’s matching receipt in ReplyPort status. A pending or deferred request is not a created draft.
You need more help
See the ReplyPort support page and include the visible error or status code. Do not send message bodies, access tokens or other credentials in a support request.
